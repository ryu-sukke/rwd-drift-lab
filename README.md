# RWD Drift Lab

RC二駆ドリフト向けのツール置き場です。

## AArmSim

リアAアーム式サスペンションの動きを3Dで確認するシミュレーターです。ストロークに応じたキャンバー・トー・キャスターを表示し、設定に応じてロールセンターも確認できます。寸法やタイヤ接地は簡略モデルです。

※ 基準ジオメトリ―はわたし個人向けとなっています
※ 絶対的な数値は信用しないでください（傾向を予測できる程度です）

- [ブラウザーで開く](https://ryu-sukke.github.io/rwd-drift-lab/AArmSim/AArmSim.html)
- ローカルでは、`AArmSim` フォルダをまとめて取得し、[AArmSim.html](AArmSim/AArmSim.html) を開きます。Three.jsは同梱されているため、外部CDNは不要です。
- スマホでは公開ページを開き、ブラウザーのメニューからホーム画面に追加できます。公開ページのオフライン起動には対応していません。

同梱ライブラリ: [Three.jsのライセンス](AArmSim/THREE-LICENSE.txt)

## AckermanSim

フロントのスライドラック式ステアリングとサスペンションの動きを3Dで確認するシミュレーターです。操舵量や車高を変えながら、左右のキャンバー・アングル・キャスターを確認できます。タイロッドやサスマウントの寸法調整、自動操舵・自動バンプ、簡易アッカーマン表示に対応しています。ジオメトリは簡略モデルです。

※ 基準ジオメトリ―はわたし個人向けとなっています
※ 絶対的な数値は信用しないでください（傾向を予測できる程度です）

- [ブラウザーで開く](https://ryu-sukke.github.io/rwd-drift-lab/AckermanSim/AckermanSim.html)
- ローカルでは、`AckermanSim` フォルダをまとめて取得し、[AckermanSim.html](AckermanSim/AckermanSim.html) を開きます。Three.jsは同梱されているため、外部CDNは不要です。
- スマホでは公開ページを開き、ブラウザーのメニューからホーム画面に追加できます。公開ページのオフライン起動には対応していません。

同梱ライブラリ: [Three.jsのライセンス](AckermanSim/THREE-LICENSE.txt)
